    Exemplo simples de declaração de classe e criação de objetos # 

    #include <iostream>
using namespace std;

class Pessoa {
    private:
        string nome;

    public:
        void setNome(string n){
            nome = n;
        }
        string getNome(){
            return nome;
        }
        void apresentacao(){
            cout << "Olá, meu nome é " << nome << "." << endl;
        }
        
};

int main() {

    Pessoa p1, p2, p3;
    p1.apresentacao();
    
    p2.setNome("Maria");
    p2.apresentacao();

    p3.setNome("João");
    p3.apresentacao();

    cout << "Pessoas cadastradas: " << p2.getNome() << " e " << p3.getNome() << "." << endl;

    return 0;
}

    A saída será:

    Olá, meu nome é .
Olá, meu nome é Maria.
Olá, meu nome é João.
Pessoas cadastradas: Maria e João.

    • Exemplo com mais parâmetros:
    #include <iostream>
using namespace std;

class Pessoa {
    private:
        string nome;
        int idade;

    public:
        //Construtor default      
        Pessoa (){
            nome = "(Não definido)";
            idade = -1;
        }
        //Construtor com parâmetro
        Pessoa (string n){
            nome = n;
        }

            nome = n;
            idade = i;
        }
        void setNome(string n){
            nome = n;
        }
        string getNome(){
            return nome;
        }
        void setIdade(int i){
            idade = i;
        }
        int getIdade(){
            return idade;
        }
        void apresentacao(){
            cout << "Olá, meu nome é " << nome << ". Tenho " << idade <<" anos." << endl;
        }

int main() {

    Pessoa p1("Ana", 21), p2 ("Maria"), p3;
    p1.apresentacao();

    p2.setIdade(22);
    p2.apresentacao();

    p3.setNome("João");
    p3.apresentacao();

    return 0;
}

    A saída será:

    Olá, meu nome é Ana. Tenho 21 anos.
Olá, meu nome é Maria. Tenho 22 anos.
Olá, meu nome é João. Tenho -1 anos.

    Composição #

    Objetos de uma classe podem ser membros de outras classes.

    • Exemplo de classes no mesmo arquivo:
    #include <string>
#include <iostream>

class Endereco {
private:
    std::string rua;
    int numero;

public:
    Endereco(std::string r, int n) : rua(r), numero(n) {}
    
    std::string getEnderecoCompleto(){
        return rua + ", " + std::to_string(numero);
    }
};

class Pessoa {
private:
    std::string nome;
    int idade;
    Endereco endereco;   // Composição: uma Pessoa possui um Endereco

public:
    Pessoa(std::string n, int i, Endereco e)
        : nome(n), idade(i), endereco(e) {}
    
    void apresentacao(){
        std::cout << "Olá, meu nome é " << nome << ". Tenho " << idade <<
        " anos. \n Moro no endereço: " << endereco.getEnderecoCompleto() << std::endl;
    }
};

int main() {
    Endereco end("Rua das Flores", 123);
    Pessoa pessoa("Maria", 20, end);

    pessoa.apresentacao();

    return 0;
}

    A saída será:

    Olá, meu nome é Maria. Tenho 20 anos. 
Moro no endereço: Rua das Flores, 123

    Observação: “Se um objeto membro não for inicalizado com o inicializador de membros, o construtor default do objeto membro será chamado implicitamente.” Caso ele não exista, ocorrerá um erro de compilação. Por exemplo, se a classe Pessoa também tivesse o construtor:

    Pessoa (std::string n, int i);

    O objeto endereco não está sendo inicializado. A classe Endereco precisaria declarar um construtor default, ou haveria erro de compilação.

    Herança #

    Uma nova classe que reaproveita os atributos e métodos de uma classe existente.

    Considere a classe Pessoa …

    hierarquia de classes..Classe base e Classe derivada, a classe derivada herda todos os membros da classe base, exceto o construtor e o destrutor.

    Polimorfismo #

    O polimorfismo permite que uma classe base declare um método que pode ser reescrito (override) pelas classes derivadas. Assim, um mesmo comando pode gerar comportamentos diferentes, dependendo do tipo real do objeto.

    Lembrar exemplo anterior:

        Pessoa p1("Ana", 21);
    p1.apresentacao();

    Aluno a1("João", 25, "1234");
    a1.apresentacao(); // método sobrescrito

    Proximo modulo? #

    Mais sobre construtores: Diretiva explicit #

    • usar quando o construtor tiver apenas 1 parametro, ou tiver mais de um parametro na declaracao mas puder ser chamado apenas com 1.

    mais sobre o contrutor default… construtor que, na declaração, inicializa todos os argumentos com valor default também é um construtor default - que pode ser chamado sem nenhum argumento.

    Ex: Pessoa.hpp

    #ifndef PESSOA_HPP
#define PESSOA_HPP

#include <string>
using namespace std;

class Pessoa{
private:
    string nome;
    int idade;

public:
    //Pessoa (string n, int i);
    explicit Pessoa (string = "", int = 0); //construtor default

    void setNome(string n);
    string getNome();
    void setIdade(int i);
    int getIdade();
    void apresentacao();

};

#endif // PESSOA_HPP
    • A implementação de Pessoa.cpp não é alterada
    • O arquivo main.cpp:
        Pessoa p1;
    Pessoa p2("Maria");
    Pessoa p3("João", 23);

    p1.apresentacao();
    p2.apresentacao();
